# Security policy

This is a reference project, not a production platform or certified baseline.
Only the current `main` branch is maintained.

Do not open public issues containing secrets, exploit payloads against live
systems or private customer data. Use GitHub private vulnerability reporting
if enabled for this repository. If unavailable, contact the maintainer through
the public GitHub profile to arrange a private reporting channel before sharing
sensitive details.

Include the affected revision, component, minimal safe reproduction, impact and
suggested mitigation. There is no guaranteed response-time or commercial support
commitment.

Scans and tests reduce risk but do not prove absence of vulnerabilities.
Production adoption requires threat modeling, identity/network design,
dependency maintenance, monitoring and an independent security review.
