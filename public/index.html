ENGINEERING NOTEBOOK / 01 / SECURE DELIVERY

Policy before
deployment.

I built this pipeline to answer a practical question: what evidence should I expect before accepting an infrastructure change or application image?

Node.js / Terraform / OPA / Checkov / Trivy

No Azure subscription is needed to reproduce the default checks. This project validates code and images; it does not deploy cloud resources.

Walk through the code Inspect current CI

How I separated the checks

01 / BEHAVIOR

Start with a small service

I used native Node HTTP so routing, security headers and failure paths stay visible. Tests exercise the real server, not a mocked response layer.

02 / INTENT

Evaluate the generated plan

Terraform produces a mock-provider plan. OPA checks that output against project-specific rules; Checkov independently inspects the declared configuration.

03 / ARTIFACT

Check what actually ships

The container runs non-root with a read-only filesystem during CI. Trivy scans the image after the smoke test, and the pipeline emits a CycloneDX SBOM.

04 / ACCEPTANCE

Make failure visible

An aggregate gate rejects failed or unexpectedly skipped mandatory checks. Snyk stays explicitly optional; Azure Policy remains an undeployed template.

FIELD NOTE / IMAGE HARDENING

The dependency audit was clean.
The image scan was not.

The initial image scan caught four high-severity advisories in the base image's bundled npm dependencies. This server did not need npm or Yarn at runtime, so I removed them, asserted their absence and rescanned without weakening the gate.

The baseline run on 2026-10-18 passed with zero high/critical image findings. That is a dated result, not a permanent security guarantee.

Read the remediation record Inspect the baseline run

What the evidence does not establish

Mock tests do not verify Azure permissions, deployment or policy propagation. A scanner pass is not a security audit. Four Checkov exceptions are documented, and Snyk has not run without credentials. The control inventory describes implementation scope, not live compliance.
